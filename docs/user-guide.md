# 用户使用指南

> 更新时间：2026-10-04

## 登录账号

打开 [登录页面](/login)，可以使用邮箱或用户名加密码登录。也可以选择邮箱验证码、Passkey、Google 或 GitHub。邮箱验证码发出后，页面会显示六位验证码输入框和重新发送的倒计时。

如果从子应用跳转到登录页，完成登录后会返回原子应用。

## 注册与验证邮箱

在 [注册页面](/register) 填写邮箱、用户名、姓名和密码。注册码可选；收到邮件邀请时，邀请链接会预填邮箱和注册码。按页面提示完成人机验证及邮箱验证后，账号即可使用。若公开注册关闭，请联系管理员。

密码需要至少 8 位、同时包含字母和数字，且强度达到页面显示的“中”或“高”；三段强度条会即时反馈。邮箱、用户名、姓名、密码及选填注册码会在进入人机验证前检查；不符合要求时可留在当前页修改。

验证邮件未收到时，先检查垃圾邮件，再在验证提示页使用重新发送。注册码和邀请链接有各自的使用或有效期限制。

## 找回密码

在 [忘记密码页面](/forgot-password) 输入已绑定的邮箱。收到邮件后，在链接有效期内设置新密码。没有绑定邮箱的账号需要联系管理员处理。

## 管理个人资料

登录后进入用户详情页，可以修改姓名、生日和头像。头像上传后可以调整位置与大小；保存后会保留原图用于以后重新裁切。删除自定义头像后会恢复按名称生成的默认头像；页面提供 30 分钟内恢复入口。

新注册的 Google 或 GitHub 账号可能默认使用该渠道的头像；已有账号的头像不会因此改变。你可以在用户详情页换用自定义头像，或恢复按名称生成的默认头像。

## 邮箱、密码和登录方式

在用户详情页选择 **Change Email / Bind Email** 添加或更换邮箱。新邮箱完成确认前，旧邮箱不会被替换。选择 **Change Password** 修改密码。

在 **Bind other account** 中可绑定 Google 或 GitHub，也可解除已有绑定。解除某种登录方式不会删除账号或当前邮箱。请保留至少一种自己能使用的登录方式。

在 **Passkeys** 中管理通行密钥。设备或浏览器是否支持 Passkey 由其自身决定。

## 注册码与应用权限

在用户详情页选择 **Apply Register Code** 可以提交注册码。成功应用后，对应的应用权限和额度会更新；每个注册码只能使用一次。可用应用和额度由管理员配置。

## 登录设备与退出

选择 **Login Devices** 查看登录设备和发起登录的应用 ID。直接在 Auth Center 发起的活动显示为 `auth-center`。可退出指定设备，也可以退出所有设备；退出后需要重新登录。

## 遇到问题

- 邮箱验证码或验证邮件未到：检查垃圾邮件，确认邮箱拼写，再等待重发倒计时结束。
- 登录提示失败：确认用户名/邮箱、密码及账号验证状态；忘记密码时使用重置邮件。
- 无法进入某个应用：请向应用管理员确认该账号的应用权限和额度。
- 账号或设备存在异常：尽快修改密码并退出所有设备。
